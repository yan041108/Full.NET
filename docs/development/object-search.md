# 业务对象搜索

使用管理端全局搜索或 `Ctrl/Cmd+K`，输入 2–64 个字符。菜单与业务对象分组显示；业务对象按标题或编号做区分大小写的字面包含匹配，`%`、`_`、`[` 等符号不作为通配符。

首版搜索最近 90 个 UTC 自然日。每个来源每页 5 项、最多 20 页，达到 100 项上限会提示细化关键词或前往来源页面。搜索不提供跨来源总数或相关度排序。单来源请求超过 8 秒显示不可用，可手动重试读取；失败不会显示成空结果。

Host 上下文只搜索已装配且当前有权访问的 Host 文档；租户上下文只搜索当前租户的企业申请。不会自动切换上下文或跨租户查找。文档 ACL、草稿可见性、软删除和申请机构范围均在来源 SQL 分页前执行，超级管理员也不能绕过文档 restricted ACL。

使用上下方向键在菜单及对象结果间移动，Enter 打开，Escape 关闭。详情通过固定路由及 UUID 重新调用来源 API：文档打开只读抽屉；申请有明细权限时打开主从详情，否则按主单读取权打开只读详情。关闭详情会清理深链；详情打开期间恢复的默认查询方案在关闭后应用到列表。权限、会话或上下文变化立即清空旧读取。

新来源在应用的 `ui/admin/src/search/objectSearchSources.ts` 静态装配。管理壳只接收来源名称、固定路由/参数名和可取消读取函数，不引用业务 API 或表。来源须先确认真实模块导航、当前精确权限和支持的上下文，并在服务端授权后返回最小摘要；不能在前端过滤无权结果、总数或敏感字段。首版同时在途来源最多两个，来源 API 与面板保持延迟加载，无中央搜索索引或缓存。

验收范围和发布限制见 [F17 验证记录](../verification/2026-11-03-object-search.md)。

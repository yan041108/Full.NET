# Host 报表定义配置

“报表定义”使用现有 Host 分组、数据源、静态 Query Port、草稿及发布版本。页面读取需要 `reporting.definitions.read`；新增、编辑、删除和发布各自使用 `reporting.definitions.create/update/delete/publish`。Host 上下文和精确权限由服务端再次验证。

只读定义角色可以单独查看列表及版本摘要，不必同时获得分组、静态查询或数据源目录权限。辅助目录仅在拥有其读取权限时请求；局部目录失败不阻断已获授权的定义列表。新建需要可用分组，以及 `reporting.groups.read`、`reporting.query_ports.read`、`reporting.data_sources.read` 以选择合法输入，不支持在页面输入任意 SQL。

## 配置数据源

“报表数据源”在 Host 下使用 `reporting.data_sources.read`，创建、编辑/禁用、删除、连接测试分别检查现有 `create/update/delete/test` 权限。新建及名称搜索入口已接入现行工具栏。配置只支持现有 SQL Server/MySQL 提供程序，端口为 1–65535 整数；服务端的目标地址、凭据保护和 TLS 规则继续生效。

列表使用脱敏摘要，编辑才读取连接元数据；服务端不返回密码。编辑时密码留空表示保留已有凭据，关闭或明确重新载入会清除本次输入的密码。保存使用详情版本，冲突保留本地输入；列表刷新不能自动提高编辑版本，必须确认放弃并重新载入。未知结果先手动刷新，不自动重放创建、保存或连接测试；连接测试会写回测试元数据，同样受该限制。禁用/删除确认绑定发起时会话，切上下文后不向新身份提交旧操作。

此页面的真实 CRUD 验收不代表外部厂商连接认证。证据见[数据源配置验证](../verification/2026-11-03-reporting-data-source-configuration.md)。

## 执行发布版本

“报表执行”需要 Host 上下文及 `reporting.executions.run`、`reporting.definitions.read`。页面只加载目录中明确发布版本的参数，不使用未发布草稿；执行请求显式携带版本号。保存或发布新草稿不会暗中改变当前输入，需要时点击“重新载入发布版本”。

首次执行冻结版本、参数及页大小，翻页沿用同一快照。修改参数后显示提示，点击“执行查询”才采用新输入并回第一页。切定义或上下文会取消旧读取/查询，清空旧参数和结果；请求失败后可手动再次执行，没有自动重放。客户端同时检查响应定义、版本、分页身份和单元格类型，最终查询预算与列权限仍由服务端裁定。

`Columns[].ColumnKey` 与 `Rows[].Values` 使用同一原始机器码。Reporting 的局部属性转换器保留字典键大小写及 null，不受全站 CamelCase 字典策略改写；客户端不猜测另一种拼写。实际已发布执行及序列化证据见[验证记录](../verification/2026-11-03-reporting-published-execution.md)。

新建和编辑只保存草稿，不发布。编辑读取详情并发版本，已保存的参数名称及默认值保持原值；切换静态查询时才采用该查询的参数定义。创建时冻结所选分组，目录刷新不能将正在编辑的草稿改挂到其他分组。

保存发生 409 或响应不明时保留本地输入并锁定后续写入。确认“重新载入草稿”会放弃本地内容并读取新版本；普通列表刷新不会静默提升正在编辑的并发版本。分组编辑采用同样的明确重载流程。新建结果不明应关闭编辑器并刷新目录确认，不能直接重发创建。

“发布”先重新读取当前服务端草稿，再单独确认名称、版本说明和发布操作。该操作建立不可变版本，发布序号与草稿并发版本含义不同。结果不明后先刷新，不能重放原发布；刷新会关闭旧确认，下一次发布重新读取详情。

模板与历史每页读取 20 条摘要。撤权、退出、换会话、Host/Tenant 切换或离开保活页面会中止旧请求、清空旧正文和对话框；迟到读取或写入不能重开旧配置。租户授权仍由原“租户发布授权”入口负责，配置页面不执行报表或创建后台任务。

聚焦证据见[验证记录](../verification/2026-11-03-reporting-template-configuration.md)。通用租户打印业务绑定和通用导出结果有效期仍按现行计划保留，不由本页面推导完成。

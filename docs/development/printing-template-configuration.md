# Host 打印模板配置

Host 后台“打印预览”提供模板草稿维护、显式发布和已发布版式示例。进入页面需要 `printing.templates.read`；创建、编辑、发布和查看版式分别需要 `printing.templates.create/update/publish/preview`，Tenant 上下文不开放维护入口。

1. 新建草稿：输入机器码、名称、HTML 和启用状态。有 `printing.form_schemas.read` 时，可从服务端已登记目录选择业务表单，默认租户档案卡片；目录不接受任意自定义键。机器码限 128 个 ASCII 字母、数字、点、下划线、短横线；名称限 128 字符，HTML 限 65536 字符。保存不会自动发布。
2. 编辑草稿：读取详情并发版本后保存；冲突或结果不明保留本地输入并锁定保存。确认“重新载入草稿”会放弃本地内容，不能直接用新版本覆盖别人修改。
3. 发布版本：单独确认当前草稿，可填至多 512 字符版本说明。历史发布内容不可变；草稿并发版本与发布序号含义不同。
4. 查看历史：模板和版本每页最多 20 条摘要，选定版本后才读取正文。净化后的版式在禁脚本 iframe 展示，占位字段保持原文，不包含租户或业务数据。

持有 `printing.form_schemas.read` 时，草稿编辑器展示所属表单的可用字段，点击可插入到光标处或替换选区，之后光标停在占位符后。插入不会保存、发布或读取业务数据，超过布局上限时保留原内容。目录读取十秒超时后可人工重试；无目录权限或读取失败仍可编辑原布局。关闭、撤权或切换会话会中止旧目录读取。不提供任意自定义字段或表达式。

新草稿切换绑定表单会保留当前 HTML；可按新字段自行调整，或明确确认后使用该表单的基础版式替换输入。基础版式只包含转义后的字段名称和静态占位符，不读取业务记录。已有模板固定原绑定，不提供换绑操作。目录失败或未知创建结果保留原绑定和输入，不自动重放保存。标记为需要业务记录的表单，仍须由租户业务入口提供可读记录，并通过当前业务权限校验；Host 选择表单不授予业务数据访问权。

启用状态立即影响模板使用资格。会话、权限或上下文变化会中止旧请求并清空页面。保存或发布结果不明时先读取确认，不自动重放写入。

Printing 拥有模板及不可变版本；更新和发布通过 SQL Server/MySQL 各自的模板行锁与结果感知事务串行化。无新表、迁移、后台执行器或绑定服务。Identity 导航 Baseline 版本为 6：保留旧模板菜单精确修复，并将系统打印分组的旧 `printing.*` 权限改为 `identity.navigation.read`，使 Host 配置和租户获授版本各按叶子权限进入。自定义目录及非匹配权限不变，由 Migrator 执行播种，API/Worker 不播种。

已发布版本的租户授权与回收沿用现有 Host 授权入口；租户真实数据预览复用业务绑定源及其当前权限校验。企业申请列表的“打印摘要”携带当前记录定位到已授权模板目录，不自动预览。定位错误时修正记录 ID 后显式重试；当前会话、业务读取、金额权限及模板授权仍由服务端复核。草稿首轮证据见[验证记录](../verification/2026-11-03-printing-template-configuration.md)，表单选择及双库真实业务旅程见[开发计划](../superpowers/plans/2026-09-16-foundation-productization.md#8109-main-打印草稿业务表单选择2026-11-05)。

# 取消本人待执行报表导出

租户中的原发起人使用 `reporting.export_tasks.cancel` 取消尚未被领取的导出。取消需要有效的当前交互会话；Host、其他租户及同租户其他用户均不可取消，超级管理员也不能替他人操作。停止自己的排队工作不要求仍保留报表发布授权或列权限。

`POST /api/v1/reporting/export-tasks/{taskId}/cancel` 提交 `{ "version": 1 }`，版本来自任务详情的 `version`；`versionNumber` 是报表发布版本，不能混用。状态为 queued、版本一致且没有租约时进入 canceled，返回最新详情。参数、发布版本、权限上限、原会话和文件引用保留。本人重复取消已取消任务不会再次增加版本。

Worker 先领取时返回 409，刷新详情查看当前状态。处理中不提供取消，不撤销未知的文件生成结果。取消先成功的任务不会再被领取。取消没有恢复入口，需要时按当前授权重新创建导出。

Vue 的“我的任务”取消入口回到原详情确认。响应丢失、服务端错误或版本冲突后先手动刷新，不自动重放写操作。开发验证状态见[本批记录](../verification/2026-11-03-reporting-and-preview-task-controls.md)；未完成的验收不能视作已交付。

## 按 ID 定位与详情身份

导出页面可以输入非零任务 UUID，去除首尾空格并规范大小写后，独立读取当前页之外的可见历史。读取沿用 `reporting.export_tasks.read` 与当前可信租户范围，既有服务端允许的同企业他人任务也可只读查看；下载、取消及按原参数再次导出继续要求本人及各自权限。详情显示任务 ID 和发起人 ID。

非法 ID 不发送请求，也不触发列表回退；任务查不到时保留请求 ID，不借其他列表行展示。输入草稿与列表分页独立，新目标取消旧详情读取。账号、会话、租户、权限或页面变化清空草稿并丢弃迟到响应。只读定位不会自动下载或写入。

## 原终态任务的独立再次导出

本人已失败或已取消的 Excel 导出，可选择“按原参数再次导出”，保留原历史，按当前授权创建独立新任务；不要求下载或取消权限。应先修正原失败原因，修改参数则使用普通新建并核对当前目录。本人成功任务只有下载明确返回 `files.file.not_found`（404）时才提供同一入口，403、限流或存储故障不判定结果缺失。排队或处理中不提供此操作。

再次导出共同要求 `reporting.export_tasks.read`、`reporting.export_tasks.create` 与 `reporting.published_definitions.read`。新任务按原定义和参数重新查询当前数据，行内容可能随数据变化。

页面先重读原任务，核对任务、发起人、发布版本、文件引用和参数未变化，再展示只读确认。原发布版本及完整参数固定，`null`、空文本、首尾空白和换行保持原值；取消不会创建。确认后通过现有接口创建一笔独立任务，服务端重新核对当前会话、定义及原版本授权，不恢复旧文件，也不自动改用最新报表版本。原任务历史记录保留。

创建回执必须对应冻结的定义、版本、参数和本人，新 ID 不得复用原任务。响应不明或回执错配时共用既有未知创建门禁，须先核对任务列表再显式解除；普通创建与重新生成使用同一规范参数身份，改变参数顺序不能绕过门禁。账号、会话、租户、权限、页面或目标变化取消本地观察，迟到结果不能打开确认或回写；取消不承诺撤销服务端已创建任务。

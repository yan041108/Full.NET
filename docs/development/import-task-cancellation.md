# 停止本人待执行导入

导入任务详情中的“取消待执行任务”停止该任务的后续调度，不撤销已写入的业务行。取消后状态为 `canceled`，不能继续执行、恢复或重试；原始文件、映射、执行计划、进度和已有错误回执保留。

允许取消的状态为 `preview_succeeded`、`queued`、`execution_partial`。Worker 正在执行时，业务事务可能已经提交而检查点尚未写回，不能直接覆盖为已取消；页面说明等待当前批次结束后刷新。如果任务已经全部完成，不再提供取消。

调用 `POST /api/v1/import-export/tasks/{taskId}/cancel`，正文为最近读取的详情版本，例如 `{"version": 4}`。版本须为正整数。服务端再次权威检查当前交互会话、当前租户、独立权限 `import_export.import_tasks.cancel` 和原上传者所有权。管理员不能代替他人取消；Host 和其他租户均不能访问此操作。停止本人待执行工作不需要仍具有来源的写权限，避免来源撤权后无法自行停止排队任务。

取消与 Worker 领取在同一任务行上竞争状态和版本。取消先成功时，任务不会再被领取；Worker 先推进版本时，取消返回 409 和 `import_export.task.cancel_conflict`。不能用旧详情覆盖工作进度。已经取消的本人任务再次请求可返回当前详情，不再次推进版本。未知写入结果或冲突后先显式刷新，不自动重放取消或其他写入。

本人任务中心识别 `canceled` 终态，并将取消入口送回来源详情页确认。后台任务、执行中任务和其他来源的取消能力不会由聚合页自行推断。当前首版不支持中断在途业务行；报表、预览等其他来源的取消与结果有效期由 C02-R2 后续差集处理。

配对迁移 `358_ImportTaskCancellation.sql` 扩展原状态约束；不新增业务表、事件、缓存或跨模块事务。结构恢复可重放，收窄回旧白名单前必须处理已存在的 `canceled` 数据。迁移恢复验收使用真实迁移建库，避免 MySQL `CREATE TABLE LIKE` 测试模板重命名 CHECK 后影响按名称恢复的验证。

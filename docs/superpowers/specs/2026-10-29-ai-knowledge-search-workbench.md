## 现状与设计依据

- `Knowledge/AiKnowledgeRetrievalService.cs` 已有受保护的向量召回：最多八个知识库、八份发布来源、三十二批向量、二百五十六块及八 MiB 向量载荷，读取限时二十五秒。SQL 使用上限加一检测超限；任何不完整、不可读或超限都拒绝整次结果，不能静默只取前八份来源。
- `Persistence/AiKnowledgeRetrievalSql.cs` 只读 AI 自有表，将发布身份、当前资源权限、可信租户与精确模型目的地绑定；向量、完整清单、计量回执、Files 原文与原生来源协议均有独立证明。新增搜索来源与文档元数据批量查询在 SQL 读取前应用文档范围，独立 HTTP 和 Vue 沿用同一证明。
- 现有 `AiKnowledgeVectorRanker` 只做固定空间下的余弦排序，不是关键词检索或语义改写；`AiKnowledgeRetrievalChunk` 已保留人工 v4、DOCX 及统一结构位置。不能把人工更正的长度当作原文坐标。
- `AiKnowledgeAnswerPipeline`、`AiKnowledgeAnswerContext`、`AiKnowledgeAnswerHistoryGuard` 已提供受控回答、来源谱系和历史重新核证。新搜索沿用这些权威边界，不另造一套绕过发布或历史权限的引用。

## 本组交付契约

独立工作台支持输入查询、明确选择知识库和文档范围、查看命中片段/来源版本及有权限的诊断，再沿既有问答入口使用同一冻结来源。读取结果明确区分无命中、版本冲突、来源不可用与范围超限；无命中不能伪造回答或推断来源不存在。

初始交付包含确定性的关键词策略和与既有向量策略在同一授权候选集上的受控比较。关键词搜索读取当前已发布完整代次中的正文，不调用模型，不创建预算或虚构零费用结算；已发布清单仍须按其真实模型身份验证。混合模型空间和超过当前有界能力的选择给出明确限制，不隐式拆成部分成功。

涉及 Embedding、改写或模型重排时，必须显式选择已批准模型与策略，复用现有操作身份、目的地校验、预算、未知用量和结算回执。不得接受任意客户端向量、候选正文或“已经授权”标记来替代服务端读取与收费准入。改写输入和输出均有界，保留原查询与实际策略版本；改写不能扩大用户选定范围。外部模型真实配置与费用授权按 A01 处理，受控测试不触发收费云调用。

策略比较输出同一输入的结果和实际执行状态。已有生产基础策略保持原值；未通过 A02 冻结语料比较的策略不自动替换生产默认。词法分数、余弦分数和后续模型分数各有名称及取值含义，不能作为统一“正确率”显示。

## 权限、版本与来源

收费策略比较使用独立 `ai.knowledge_search.compare`，适用于 Host/Tenant，并在收费前、载荷读取和交付复核时持续要求该权限；不依赖仅限 Host 的聊天发送权限，也不授予聊天或回答生成能力。比较只派发一次已批准查询 Embedding，分别交付词频和余弦排名，普通结果不包含完整候选计数；用量缺失保持 unknown。该关联切片已完成上述本地聚焦验收，不能据此勾选整组。

新增稳定搜索操作权限与独立诊断权限，按现有精确命名规范登记。搜索同时保留知识库、文档、原文件及索引读取权限；诊断不得因为调用者能看某个片段就返回其他候选、隐藏资源计数、模型秘密或内部提示。普通搜索不要求聊天发送权限，后续回答仍执行独立 Chat/预算准入。

知识库/文档筛选在资源 SQL 与完整来源读取前应用，不在获取无权正文后再过滤。所有候选、邻接块、父子上下文、策略比较和历史来源复核先按可信租户及当前会话授权，再读取正文。相同来源不得因补全分支绕过完整代次或 Files 证明。

服务器冻结发布、文档、文件版本、完整清单摘要和策略身份；响应前再次核验完整来源。来源发生变化时返回冲突/不可用并清空旧展示，不能把上一次命中悄悄替换为新发布的同序号块。来源预览继续经既有独立授权接口；客户端只传真实服务器位置，不推算高亮坐标。人工补写显示无原文位置，更正保留原上下文。

返回片段采用有界长度与稳定分页/选择语义，结果范围和总量必须真实。上下文补全使用完整清单的真实结构及单独总预算，不能拼接全部父文档；重复和来源集合身份参与校验。原生文本、表格、OCR 与人工修订均沿各自来源协议处理，未知协议失败关闭。

真实嵌入图片补全复用统一解析快照的 `Image.Parent`，精确匹配此前已验证的非图片原文锚点；`AiKnowledgeParsedStructure` 已拒绝不存在、尚未出现或图片套图片的父位置。新 `POST /api/v1/ai/knowledge-search/relations` 已接入完整候选、租约与最后交付复核，不增加模型调用、业务表或 SQL。原始块和人工修订的全部引用片段均参与关系证明；合并块可以同时包含父子两端，补写不产生原文位置。按锚块的真实父位置补全父块与同父图片子块，最多五块、32768 个 UTF-16 单元和 128 条边，超限整次拒绝。没有关系为 `none`；父锚点有证明但父正文没有进入当前发布索引为 `parent_not_indexed`，父块序号为空；双方正文齐备为 `complete`。每条边带双方原文位置，块序号相邻、同页或标题相似不构成关系。普通文本不推断 Markdown/HTML 标题树；原文件坐标和下载继续沿既有独立授权。该切片已完成上述本地聚焦验收，不能据此勾选整组。

## 实现落点与批次

### 受控改写与模型重排

新增独立 `POST /api/v1/ai/knowledge-search/refine` 与 Host/Tenant 精确权限 `ai.knowledge_search.refine`，同时要求比较和全部正常读取权限，不附带聊天发送/读取权限。处理模型必须是所选全部知识库当前批准的生成模型及精确版本；Embedding、完整来源和文档选择使用已有冻结契约。三种显式模式分别为改写（三次模型派发）、重排（两次）及改写后重排（四次）。原查询的词法/向量、改写查询的词法/向量及模型排列分别显示，不修改生产基础策略或原查询，不写答案/聊天历史。后续回答继续使用原问题和冻结来源，经过既有独立回答准入。

每次模型调用使用独立 UUID v7 操作身份，沿原预算、已知/未知用量和原作用域独立结算。全部来源、读取权、精确模型/目的地在每个阶段和响应前重新核证。模型拒绝作为明确结果保留已结算回执；改写拒绝停止后续步骤，重排拒绝保留独立基础排名。无效 JSON、重复/扩展字段、非法身份、工具/非文本或超限导致整次实验失败，不自动重试；早期已派发步骤不抹去费用或记零。

改写只接受 `query/refusal`，沿原查询的 512 UTF-16 单元、16 个词项及每词 64 单元上限。重排候选只来自服务器已授权向量排名前八块，最多 32768 UTF-16 单元、每块 8000 单元，完整提示 cl100k 最多 4096 Token，超限整阶段拒绝，不静默截正文。模型只能返回服务器临时候选 ID 的完整排列或空排列拒绝，不返回正文、分数、来源、URL 或工具。展示 `ordinal_priority` 为服务器据排列生成的序数优先级，不能表示置信度或准确率；独立预算和候选前缀范围在页面说明。实际云质量与费用仍归 A01/A02，本批只使用隔离受控模型验证协议、收费及真实运行链路。

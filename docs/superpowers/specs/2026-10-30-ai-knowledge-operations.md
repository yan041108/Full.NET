## 权限与来源边界

运营页面使用独立精确读取权限，不能因为普通读者能搜索某库，就交付维护诊断。任务处置、评估集维护/批准/执行、财务汇总分别授权；页面隐藏之外 Endpoint 和服务均重新授权。可信 Host/租户来自当前上下文，超级管理员不绕过隔离及当前会话。

任务及过期元数据仅属于当前主体管理的知识库；普通只读成员不因此成为维护者。分页、计数、筛选使用同一可见范围，不能先统计全租户再过滤页面。默认只交付对象身份、机器状态、时间、版本和安全失败码，不返回原始异常、文件路径、模型配置或正文。FAQ 维护身份不构成私人答案读取权；展开正文、来源或进入 K02/K04 维护仍走原有完整来源、父图与窄用途反馈权限。到期和来源失效待办可以显示维护者自己的受管根及安全状态，不能泄露不可读父叶的标题或内容。

结构化反馈标签继续复用现有审核读服务；无答案事件仅保存结果分类和有界来源身份，不收集原用户问题或答案。私人会话信息不经运营接口交付。反馈转修订、转 FAQ 或人工脱敏候选分别进入已有专属入口，不能把审核 Read、运营 Read 或差评计数提升为私人正文权限。来源撤回、审核变化、父发布替换或叶撤权后，数据集读取、执行、导出和比较均重新复核。

财务汇总使用独立范围级财务权限，结果限定可信 scope 与有界时间段，不能由普通库维护权得到整租户账单。公开财务结果不带会话、问题、主体、请求摘要、TraceId 或模型凭据。按库归属只统计服务器实际捕获的准确关系；历史缺失归属显示为未归属，不能按 RunId、当前模型或时间猜测。未获范围财务权时，不返回全局未归属计数。

## 任务与处置流程

在 `Features/ManageKnowledgeOperations` 组织公开查询和 DTO，数据读取集中在本模块查询侧。普通文档与 FAQ 静态修订使用显式闭合类型，保留 FileId/FaqRevisionId 二选一及普通入口排除条件。列表按稳定游标分页，限定时间/库/状态筛选和返回上限；禁止先读全量再内存分页或静默截断后声称完整。

页面并列显示准备状态、索引任务状态、完整代次资格、草稿/审核及当前发布状态。`completed` 只表示相应处理完成，不等于已审核、已发布或当前可检索。仅在有真实持久观测时展示阶段起止/已处理数量；旧任务显示未记录，不倒推百分比或耗时。新阶段记录来自原 Worker 的实际转换，随原任务租约及代次条件写入，陈旧 Worker 不覆盖新任务。

失败处置复用原重试、校对、重建、审核与发布操作及各自权限、版本和收费确认；不增加后台自动重试、自动索引或发布。未知收费先走既有对账/准入边界，不通过一个“重新处理”按钮重复派发。取消/失败/过期与待处理分别呈现，按原 requestKey 保留不确定结果。过期或失效来源不回退旧发布，也不删除被历史、父图或文件引用保护的资源。

## 不可变数据集与策略比较

接续实施时，数据集归属既有知识库，复用可信租户、库所有者及现有成员/角色/机构读取关系，不另造评估空间或身份系统。创建、编辑与转移限定维护者；独立批准者仍须有当前库读取、专属批准和全部来源资格。私人反馈派生以 restricted 为下限，复制到另一库时重新核对两端及完整来源，不以已脱敏声明清空来源。此段为下一批边界，当前元数据列表不代表已实现数据集。

原有反馈评估准入只返回短期候选/一次样例交付，不能直接作为长期持久授权。持久样例必须由服务器保存准确反馈/审核及原消息的完整来源和内容绑定；原答案字节改变也须失效，不能只依赖 feedbackVersion 或旧 LineageHash。公开样例只有人工输入的脱敏字段，不自动读取并复制原用户问题或答案。编辑/恢复/复制、样例移出运行及导出再导入都不能把保留的派生正文改成独立来源；冻结数据集记录不可变来源足迹，后续仍复核。

采用 Ai 自有静态记录保存数据集根、追加修订、样例、批准记录、策略版本及运行结果；双库成对迁移并登记静态读取器。根保存操作者、可信 scope、CAS 版本；修订保存完整有界规范 JSON 与摘要，已冻结修订不可覆盖。样例来自人工输入或既有 `AiFeedbackEvaluationService` 的当前准入，保留反馈/审核和完整来源证明，不接受展示引用替代完整依赖。

保存样例前明确人工脱敏确认；冻结/批准时再次复核，批准者不能是该修订编辑者。独立合成样例保存明确人工依据；来自生产反馈的样例不得删除来源后改成独立样例。编辑、复制、恢复、导出再导入均保留原来源限制。正文及总样例数、规范 JSON 字节、图和依赖使用明确预算；缺失、环、冲突、超限一律拒绝，不截断。数据集来源核证复用既有静态来源能力，避免历史、FAQ、评估服务相互递归或形成 DI 环。

策略版本冻结原查询、关键词/向量方式、有界候选、批准模型及精确版本、Prompt/解析/分块/索引身份和受控改写/重排选项。模型目的地及受保护配置版本由服务器核证，公开摘要不包含凭据。比较必须使用同一数据集修订和输入范围；基线与候选分别记录，不自动替换生产基础策略。无法取得历史所需的准确模型或发布身份时标为不可执行，不能悄悄采用当前版本。

执行前展示样本数、策略、模型、预算和调用上界，显式确认后建立稳定运行/子操作身份；每阶段复用既有收费服务和原作用域结算。原会话、全部来源、完整模型目的地在收费前、实际派发和交付前均复核。保留未知用量、限流、超时、熔断、静默日志及收费 HTTP 无自动重试。取消或连接中断不重新生成操作身份再次收费；待对账操作不算失败后免费重试。

运行结果逐样例保留完成/失败/跳过/未运行、原因及原始指标；分母包含全部冻结样例，不能过滤失败后显示提升。检索命中、有效引用、拒答判定与人工语义支持分开；有引用不能自动推导语义正确。参考构造、受控实际模型和外部导入结果有不同来源标记，外部报告不冒充服务器执行。复用 `tests/ai-evaluation` 已有评分语义和冻结版本，避免另造相反评分器；生产代码不能反向依赖测试项目，必要的共用纯协议放在实际消费者共同使用的位置。

## 冻结评估集批次的具体协议（实现已接通，集中验收中）

`347_AiKnowledgeEvaluationSets` 新建本模块集合根、仅追加修订和仅追加审核记录；不写其他模块、不创建Files对象、不派发模型。根用版本CAS，原请求键和操作者/原头/正文指纹用于幂等；每次编辑、冻结及恢复都追加新修订，批准与撤回只追加决定并更新根版本，不能覆盖冻结正文。写入和完整资格复核在本地事务中完成，写后失败回滚；来源/身份端口在事务外，原会话重核后使用联合SQL。来源和锁写入阶段各25秒，整次用例90秒，死锁409且不自动重试。

同一修订最多8个样例；规范正文768KiB。集合累计最多8个反馈来源、16个正文贡献者，累计规范足迹320KiB；每个来源继续复用K04的16KiB/真实父图/叶依赖限制。写前和读后使用同一规范JSON预算，拒绝重复、未知字段、损坏、超限或截断。移出所有派生样例后集合仍保留来源，编辑、同库复制和恢复也保留全部累计限制及贡献者；当前批准者不得属于累计正文贡献者。历史读取仍复核当前保留足迹，不能借历史或复制回退来源。此批复制仅支持同库；评估集导入/导出没有开放，不能绕过来源协议。

旧短期反馈候选不直接进入持久化。新窄用途 `ai.knowledge_evaluation_sets.feedback` 先核对目标准确库版本、所有权及restricted分类，再由服务器核证已批准反馈、完整答案谱系和原答案字节。独立的Data Protection用途签发准备凭据，绑定原主体/租户/会话/目标库版本、人工字段、完整来源和原答案摘要，到期不晚于旧候选。保存只接受新用途凭据并核对同一人工字段、当前目标版本；凭据不落库。后续读取、批准、复制和恢复继续核对私人窄用途及所有真实父叶资格；旧审核Read和集合Read不隐含私人正文权，不返回原用户问题或生产答案。

公开读、创建、追加、冻结、恢复、复制、批准、撤回和私人来源分别使用精确权限；独立批准沿用当前知识库成员/角色/机构读取关系，写入限所有者。有界列表按8项窗口读取，最后在单条SQL共同核对选中根及完整来源，不能逐条等待后交付旧资格。已提交操作若在交付复核时来源失效，返回`deliveryState=source_unavailable`及准确保存身份，`workspace=null`；不返回失效正文，也不把已提交操作伪装成可用新身份重试的失败。

正式Vue提供独立导航、人工编辑、明确脱敏确认、冻结、独立审核、同库复制及准确历史恢复；反馈审核面板接入“重新核对来源→明确确认→持久保存”，不下载或存储token。未知网络结果仅显式重放原请求，范围/会话/权限变化清空并忽略迟到响应。九项公开操作及14个引用Schema已与双库JIT运行时OpenAPI核对，生成检查零漂移；实际Native与真实页面仍必须使用新产物，不能沿用维护元数据批次。

## 费用、用量与延迟

账本仍是费用权威，结果按币种、原月份、价格版本及 usageStatus 汇总。已知金额、保守预留、未知/待结算项分别显示；总额有未知项时保持未知或明确部分已知，不能 `COALESCE` 成零。不同币种不相加，不把已结算零调用与没有观测混淆，也不把保守记账称为供应商已核实账单。

延迟来自单调时钟实际观测，写入服务器结果或有界操作观测记录；历史缺失值保持 null。平均值和最近秩 P95 仅基于有测量项并显示测量数、失败数及缺失数，不能用创建/修改时间差、租约时长或排队时长冒充模型耗时。排队、处理和端到端延迟分别定义，不混成一个“速度”指标。对象身份仅用于授权及记录关联，不加入高基数 Metrics 标签。

## Vue 与关联验收

正式 Vue 提供任务/待办、冻结评估集及比较、费用/延迟三个关联区域，闭合动态导航与精确操作权限。读者不出现诊断入口；所有失败、未知费用、未记录阶段、未发布完成任务均有明确状态。沿用文本渲染与 ProblemDetails；会话切换、409、撤权或来源变化后清空旧私有内容。收费、批准、发布等操作保持原独立确认，键盘和移动端可完成主要流程。

按完整关联批次集中验证：先贯通任务/待办与公开页面，再贯通数据集/策略/运行/费用和页面；内部 SQL、DTO 或单个帮助器不算整组完成。聚焦 Unit 验证边界、摘要、状态及未知语义；双库覆盖隔离、精确权限、CAS/幂等、失败恢复、陈旧租约、独立批准、全来源撤回及真实账本汇总；涉及 Host.Api 的公开流程用新输入实际 Native 运行。正式页面在桌面/移动真实栈验证实际操作、拒绝、清空、所有 axe 规则和无横向溢出。复用已验收 K01–K04 范围，不复制整仓、不跑全量、不更改全局门槛或 Workflow。

验收前冻结自有生产/测试/公开契约及消费者摘要，保留原失败和外部无关漂移；发布等待真实退出 0、完整标记及新 ELF，不采用旧产物。真实云质量和容量未运行则保持未验收。K05 全部关联能力实际通过后才关闭工作组；本设计不作为代码或验收证据。

## 实际运行批次实施细化（2026-10-30，关联实现已接通，验收中）

实际运行使用既有公开比较/受控改写服务的权威内核，不能另造只排序不派发的运行器。策略根按CAS追加不可变版本，绑定准确已批准集合修订/批准身份、原人工问题、完整发布范围、批准模型版本和目的地摘要；关键词/向量、关键词/改写重排、向量/改写重排为闭合策略对，Prompt与测量协议由服务器固定版本，不接受任意客户端提示词。每次比较使用同一原问题和范围，改写问题另行记录，不覆盖原问题。策略不自动激活生产配置。

运行先显示准确样例数、模型版本、现有预算逐次准入规则及调用上界，再要求明确收费确认。服务器在调用前持久保存每个样例的原阶段UUID身份并CAS领取；后续只执行尚未运行样例，一项阶段在同次作用域只能取号一次。比较向量及改写/重排复用既有收费通道、原作用域结算和完整来源/目的地/原会话复核。重复HTTP请求读取原状态；未确认结束、未知费用或丢失结果不能用新模型身份自动重派。跳过、失败、未知、运行中和未运行均保留在总分母。

结果区分实际检索输出、受控模型改写/重排与人工证据支持判断。没有生成模型答案的检索比较不输出虚构的回答准确率、引用有效率、Recall或拒答命中率；未提供可核验片段真值的指标保持未记录。人工支持判断为独立来源标记，不能冒充模型自动评分。R02冻结评分语义与A02真实云质量结论不改变。延迟以实际单调时钟测量完整策略对操作，显示测量数/缺失数/失败数；服务未独立测量的单策略耗时不猜测。

原阶段操作UUID与运行/库的显式绑定用于查询账本，不能用旧RunId或时间推断历史归属。费用仅从实际账本原月份/价格版本/币种及未知用量状态汇总，金额返回精确十进制文本或null；运行读取不隐含范围财务读取权。最小回答观测与真实成功回答同事务保存机器拒答分类、明确候选库关系和实际测量耗时，不保存用户问题或答案；其分母只包含成功持久化的回答，不是所有 HTTP 请求，接口失败不伪装成已保存的拒答。运行失败/未知/跳过仍保留在运行分母，任务及账本保持各自失败口径。现有差评按当前授权范围计数，具体为窗口内更新、当前未撤回且待审核的记录，不冒充全部历史差评。运营当前库复用既有审核/脱敏入口，保留聊天读取父权限与原独立审核、私人用途边界。各读取及人工审核入口仍核对集合和完整策略来源，失效后清空旧结果。双库349/350、十四项公开操作、静态读取器、生成SDK、正式运行面板及独立财务入口均已通过本批聚焦验收；实际账本的已知正费用、USD/CNY 分币种与未知费用 null 均有实际 Native 及页面证据。

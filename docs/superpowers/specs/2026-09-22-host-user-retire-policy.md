# Host 用户删除/退役策略（清单 ID07）

**日期**：2026-09-22
**状态**：已实现

## 产品决策

| 操作 | 语义 | 可逆 |
|------|------|------|
| **禁用** | 暂停登录与会话；资料保留 | 可启用 |
| **退役** | 永久归档账号；清空会话与 OIDC 授权；列表仍可审计 | **不可**启用 |
| **物理删除** | 不支持 | — |

## 规则

1. 存在**活动租户成员关系**（`fn_identity_tenant_member.Status = Active`）的用户不得退役。
2. 最后一名活动超级管理员不得退役（与禁用一致）。
3. 已退役用户调用 `enable` 返回业务错误；须新建账号。

## API

- `POST /api/v1/identity/host/users/{userId}/retire`
- 权限：`identity.users.retire`

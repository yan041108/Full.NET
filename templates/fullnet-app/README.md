# Full.NET Application Template

This template creates an independent Full.NET application with a versioned framework source bundle under `framework/fullnet/`.

## Parameters

| Symbol | Description | Default |
| --- | --- | --- |
| `name` | Application name | `App` |
| `owner-key` | Official owner key for naming profile | `demo` |
| `database` | `sqlserver` or `mysql` | `sqlserver` |
| `preset` | `minimal` or `platform` module preset | `minimal` |
| `http-port` | Local HTTP port | `5180` |

## Create an app

```bash
dotnet new fullnet-app --name Demo --owner-key demo --database mysql --preset platform --http-port 5180
```

## Layout

- `framework/fullnet/` — managed framework source bundle and `framework-manifest.json`
- `src/App.Host.Api/` — application-owned API host referencing framework hosts
- `appsettings.json` — runtime configuration including `FullNet:Modules`

Secrets are not generated by the template; configure connection strings and signing keys in local user secrets or environment-specific settings.
